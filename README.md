# نظام إدارة مخزن قطع غيار السيارات (نسخة تجريبية)

ده النظام اللي عملته لإدارة المخزون والمبيعات والمشتريات وحسابات العملاء في
محل قطع غيار. النسخة اللي هنا **للعرض بس**: كل البيانات وهمية، ومفيش سيرفر
ولا قاعدة بيانات وراها، فتقدر تتصفح كل الشاشات وتشوف الأرقام والتقارير بدون
ما تحتاج حساب.

## الفكرة

كل حاجة بتدور حوالين: أصناف، مخازن (ممكن أكتر من مخزن)، عملاء وديونهم،
فواتير بيع، طلبيات شراء، مرتجعات، جرد دوري، وتقارير تورّيني فين الفلوس
رايحة وجاية بالظبط.

أهم حاجة عندي إن الأرباح تبقى **دقيقة مش تقريبية**. لما أبيع قطعة، عايز
أعرف بالظبط اشتريتها بكام، فبنيت نظام دفعات (Lots) بيتتبع كل عملية شراء
لوحدها، والبيع بياخد من أقدم دفعة أول (FIFO).

## إيه اللي في النسخة التجريبية

- بتفتح على طول بحساب تجريبي، من غير شاشة دخول.
- فيها حوالي شهرين ونص من الشغل الوهمي: فواتير، طلبيات، مرتجعات، دفعات عملاء.
  الأرقام متسقة مع بعضها (الربح بيتحسب بنظام الدفعات، ورصيد العميل بيطابق كشف حسابه).
- الحفظ والتعديل متعطلين. أي ضغطة على «حفظ» بتظهر رسالة بتشرح اللي كان
  هيحصل في النسخة الحقيقية.
- صفحة **جولة سريعة** (من القائمة الجانبية) فيها شرح بسيط لكل جزء في النظام.
- البيانات بتترجع لأصلها مع كل تحديث للصفحة.

## التقنيات المستخدمة

- React + TypeScript + Vite
- Tailwind CSS (v4)
- Recharts للرسوم البيانية، و xlsx لتصدير التقارير لإكسل
- PWA
- النسخة الحقيقية: Supabase (Postgres + صلاحيات + دوال SQL للمنطق المحاسبي)

## إزاي النسخة التجريبية بتشتغل

الصفحات نفسها هي صفحات النظام الحقيقي من غير تغيير. اللي اتغيّر هو
`src/lib/supabaseClient.ts`: بدل الاتصال بـ Supabase، بيرجّع عميل بديل
(`src/demo/mockClient`) بيقرأ من قاعدة بيانات وهمية بتتولّد في الذاكرة
(`src/demo/seed`) وقت فتح الصفحة.

```
src/demo/
  mockClient/   بديل Supabase: فلاتر، ترتيب، جداول متداخلة، والكتابة معطلة
  seed/         مولّد البيانات الوهمية (دفعات FIFO، فواتير، مرتجعات، أرصدة)
  guide/        صفحة الجولة السريعة
```

## التشغيل محليًا

```bash
npm install
npm run dev
```

مفيش `.env` ولا مفاتيح مطلوبة.

## الاختبارات والبناء

```bash
npm test          # اختبارات البيانات الوهمية والعميل البديل
npm run lint
npm run build
```

النشر على GitHub Pages تلقائي من `.github/workflows/deploy.yml` (في إعدادات Pages اختار Source: GitHub Actions). وبيتنشر كمان على Vercel أو Netlify كموقع ثابت عادي. الروابط بصيغة `/#/صفحة` عشان تشتغل على أي استضافة من غير إعدادات إضافية.
